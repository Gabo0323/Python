# Proyecto 8 — Visualización de Datos en Python
 
Notebook de Google Colab con ejemplos prácticos de visualización de datos usando **Matplotlib** y **Seaborn**.
 
**Autor:** Gabriel Vega
 
## Contenido
 
- **Gráfico de líneas**: comparación de dos series (`plt.plot`).
- **Gráfico de barras**: dos conjuntos de datos superpuestos (`plt.bar`).
- **Barras + histograma**: 1000 valores aleatorios (distribución normal) graficados como barras y como histograma.
- **Scatter plot**: tres series de puntos con distintos marcadores y colores.
- **Heatmap**: mapa de calor de una matriz aleatoria 200x300 con Seaborn.
